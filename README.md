# 🚗 Sistem Parkiran Alvira

Aplikasi manajemen parkir berbasis web yang dibuat menggunakan PHP dan MySQL. Aplikasi ini membantu pengelolaan data kendaraan, member, tarif parkir, area parkir, transaksi kendaraan masuk dan keluar, serta laporan aktivitas.

## ✨ Fitur Utama

- Login dan autentikasi berdasarkan role.
- Manajemen data member dan kendaraan.
- Manajemen tarif parkir.
- Manajemen area parkir dan kapasitas.
- Pencatatan transaksi kendaraan masuk dan keluar.
- Pembuatan nomor karcis otomatis.
- Perhitungan durasi dan biaya parkir otomatis.
- Cetak struk transaksi.
- Log aktivitas pengguna.
- Laporan transaksi parkir.

## 🛠️ Teknologi

- PHP
- MySQL
- Bootstrap 5
- HTML
- CSS
- JavaScript

## 👥 Hak Akses

- **Admin:** Mengelola data dan seluruh fitur administrasi.
- **Petugas:** Mengelola proses operasional parkir.
- **User:** Mengakses fitur sesuai hak akses pengguna.
- **Owner:** Memantau data dan laporan parkir.
